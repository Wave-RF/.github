# Getting help

This is the default support page for [Wave RF](https://github.com/Wave-RF) repositories. A repository with its own `SUPPORT.md` (for example [WaveHouse](https://github.com/Wave-RF/WaveHouse/blob/main/SUPPORT.md)) has more specific guidance.

| You have… | Go here |
| --- | --- |
| **A bug** | Open an issue in that repository, with steps to reproduce and the version you're on. |
| **A feature idea** | Open an issue in that repository, describing the problem you're trying to solve. |
| **A "how do I…?" question** | The repository's **Discussions** tab, if it has one. Otherwise, open an issue. |
| **A security vulnerability** | **Not a public issue.** Follow the [security policy](https://github.com/Wave-RF/.github/blob/main/SECURITY.md). |
| **A WaveHouse Cloud question** | [wavehouse.cloud](https://wavehouse.cloud) |
| **A business or partnership enquiry** | <hello@wave-rf.com>. |

## What to expect

Our open-source projects are maintained by a small team. Support is **best-effort, with no SLA**. If a thread goes a week without an answer, feel free to bump it.

Participation in any Wave RF space is governed by our [Code of Conduct](https://github.com/Wave-RF/.github/blob/main/CODE_OF_CONDUCT.md).
